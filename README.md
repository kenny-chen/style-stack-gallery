## Layout

```
posters/       single-style posters
fusions/       two or more styles stacked
storyboards/   3-row and 6-panel boards (left image / right editorial)
magazine/      covers and editorial layouts
scripts/       recopy from the local Cursor assets folder
```

## How a stack is written

Each prompt names **medium**, **composition**, **palette/type**, and **subject** as separate layers. Example:

`Octane / Raytraced` + `Luxury & Premium` + `Photo-Based Hero` + `Napoléon`

Conflicts are resolved on purpose (for example: kinetic type vs. quiet luxury serif, or comic inking vs. four-color luxury inks).

## Recopy from Cursor

If new images land in the Cursor assets folder:

```powershell
powershell -File scripts/copy-from-cursor-assets.ps1
```

Source path is set in that script (Cursor project `assets` directory).
